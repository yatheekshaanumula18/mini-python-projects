# Student Marks & Grade Calculator

A beginner-friendly Python command-line project that accepts marks for four subjects and calculates total, percentage, grade, and pass/fail status.

## Requirements
- Python 3.8 or newer
- No third-party packages

## Run
```bash
python main.py
```

## Features
- Validates marks from 0 to 100
- Calculates total and percentage
- Assigns a grade
- Checks pass/fail (35 marks minimum in each subject)

## Note
This is an educational demonstration. You can change the subjects, grade ranges, or pass mark in `main.py`.
