# Python To-Do List

A simple command-line task manager. Add tasks, view them, mark them complete, and delete them. Tasks are saved in `tasks.json`, so they remain after you close the program.

## Requirements
- Python 3.8 or newer
- No third-party packages

## Run
```bash
python main.py
```

## Features
- Add and view tasks
- Mark tasks as complete
- Delete tasks
- Save tasks locally in JSON format
